# About the data

This project uses a 1,000-record telecom customer dataset with 34 analytical variables supplied through Colorado State University Global course materials for a Statistics in Business Analytics portfolio assignment.

The course materials describe the records as a random sample of approximately half of an unnamed telecommunications company's customers. Identifying information was removed for privacy, and the `income` field was obtained by the telecommunications company from an outside vendor. The original telecommunications company, income-data vendor, collection dates, geography, and upstream data provider are not identified in the available course materials.

## Redistribution

The original workbook is not included in this repository because redistribution rights have not been established. This repository does not provide sample rows from the source dataset.

Users who independently have authorized access to the source workbook can place an unchanged local copy at:

```text
data/raw/TelcoExtraCSU-Global.xlsx
```

The `data/raw/` directory and common spreadsheet/CSV data files are ignored by Git to reduce the risk of accidentally committing course-provided source data.

See the main `README.md` for the documented notebook execution order and reproducibility checkpoints.
